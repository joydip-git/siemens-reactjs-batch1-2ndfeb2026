component lifecycle
	effect hook: useEffect()
	
	useEffect(
		//effect function
		
		()=>{ 
			//effect code

			return () =>{ 
				//clean up code
			}
		},

		[] <- dependency list (optional)
	)

	1. no dependency list	=> effect code will be executed always
	2. dependency list with dependencies => effect code will be executed ONLY when any of the dependency factor's value changes
	3. a blank dependency list => effect code will be executed ONLY once (after mounting) until the component is unmounted
	4. if you have all versions of the useEffect(), all of the effect codes will run very first time
	5. all cleanup codes will run from the second cycle (render) onwards for any component and they will run before the effect code
	6. no dependency list	=> clean-up code will be executed always (2nd render onwards at the beginning)
	7. dependency list with dependencies => clean-up code code will be executed ONLY when any of the dependency factor's value changes, but from next cycle, at the beginning
	8. a blank dependency list => clean-up code will be executed ONLY once when the component is unmounted

State Management with Redux
-------------------------------
store (object) => collection of states and ****
	state (object) => an object with properties
	reducer (function) => a function which controls how to update the current state. produce a new state and return the same to the redux store

action (object) => send to store from a subscribed component with one particular information: what type of action to perform on the state and optionally one more item which is known as payload
{
	type: 'increase',
	payload: 2
}

dispatch() => a method to send action object from component to store (supplied by store)
